# Minecraft Server Backup

这是 Minecraft Java 版服务器备份仓库，用于保存服务器配置文件、白名单、管理员列表等重要配置。

> 注意：本仓库不建议直接存放完整世界压缩包 `world.zip`。  
> 世界存档体积较大，保存在 GitHub Releases 下。

---

## 服务器信息

- 服务端类型：Minecraft Java Edition Server
- 管理面板：MCSManager
- 主要存档目录：`world`
- 主要配置文件：`server.properties`

---

## 仓库用途

本仓库主要用于备份以下文件：

```text
server.properties
ops.json
whitelist.json
banned-players.json
banned-ips.json
